---

# 🔹 First: What problem are we solving?

When you write:

```csharp
foreach (var x in four)
{
    Console.WriteLine(x);
}
```

👉 The compiler needs a way to:

1. Get elements one by one
2. Move to next element
3. Know when to stop

---

# 🔹 What `foreach` really does (important)

Your `foreach`:

```csharp
foreach (var x in four)
```

👉 is translated roughly to:

```csharp
var enumerator = four.GetEnumerator();

while (enumerator.MoveNext())
{
    var x = enumerator.Current;
    Console.WriteLine(x);
}
```

---

# 🔥 So what do you need?

To support `foreach`, your class must provide:

### ✔ `IEnumerable`

```csharp
GetEnumerator()
```

### ✔ `IEnumerator`

* `MoveNext()`
* `Current`
* `Reset()`

## Step 1: Minimal Enumerator

```csharp
class Enumerator : IEnumerator
{
    private int[] _data;
    private int _index = -1;

    public Enumerator(int[] data)
    {
        _data = data;
    }

    public object Current => _data[_index];

    public bool MoveNext()
    {
        _index++;
        return _index < _data.Length;
    }

    public void Reset()
    {
        _index = -1;
    }
}
```

}
