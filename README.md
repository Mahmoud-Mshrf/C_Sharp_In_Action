# C# In Action

A collection of practical C# examples, experiments, and small projects created while studying and exploring the C# language.

The goal of this repository is to understand **how C# works under the hood and how its language features are used in real code**, rather than simply memorizing syntax.

## 📚 What You'll Find

The repository contains focused examples covering a wide range of C# concepts, from fundamental language features to more advanced topics.

### Core C# Concepts

* Variables and basic syntax
* Properties
* Constructors
* Access modifiers
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Casting
* Enums
* Collections

### Advanced Language Features

* Generics
* Delegates
* Generic delegates
* Lambda expressions
* Expressions
* Events
* Event handlers
* Operator overloading
* Indexers
* Iterators
* Enumerators
* `IEnumerable` / enumeration concepts

### Other Topics

## 🎯 Purpose

This repository serves as a personal **C# learning laboratory**.

Instead of keeping all examples in one large project, concepts are separated into focused examples so that I can:

1. Study a specific language feature.
2. Experiment with different approaches.
3. Observe the behavior of the language.
4. Write small tests and examples.
5. Build a stronger understanding of C# fundamentals.

## 🧠 Learning Approach

The focus is not only on **"how do I write this?"**, but also on questions such as:

* Why does this feature exist?
* What problem does it solve?
* How does it behave?
* What happens internally?
* When should it be used?
* What are its limitations?
* How does it relate to other C# features?

## 🚀 Running the Examples

Clone the repository:

```bash
git clone https://github.com/Mahmoud-Mshrf/C_Sharp_In_Action.git
```

Open the solution:

```bash
cd C_Sharp_In_Action
```

Then open the solution with your preferred IDE or run an individual project using the .NET CLI.

For example:

```bash
dotnet run --project <project-path>
```
